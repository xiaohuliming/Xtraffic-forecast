POST-MORTEM (design lessons, recorded for the paper's honesty section):
  1. SOFT oracle over K=6 correlated anchors smears the routing: router weights are near-uniform
     (base .22 / persist .25 / decay .22 / daylag .18 / up .06 / down .06), nearly IDENTICAL for
     affected vs unaffected and across seeds. A blurred average of 6 anchors is a WORSE anchor
     than s0f's decisive 2-anchor blend. The K=2 oracle worked because its target was sharp.
  2. Neighbor LEVEL anchors are mis-specified: another road's absolute flow level is the wrong
     magnitude for my node (lane/volume mismatch). The oracle correctly assigns them only ~6%
     each, but the remaining smear still pollutes. A valid version would be deviation-space
     (my baseline + neighbor's standardized residual x my sd), not level-space.
  3. daylag raw values carry day-to-day noise that the median baseline smooths -- as an anchor it
     adds variance more than signal (~18% weight yet performance collapsed).
  4. Router conditioned only on (d,u) cannot learn WHICH anchor suits WHICH node.
