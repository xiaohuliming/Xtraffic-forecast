## 对改进路线的含义

1. 插件在 BiST 上的长预算回升不来自辅助损失的持续牵引，也不来自插件参数本身的容量。把辅助损失退火到零后曲线更差，说明 oracle 监督在后期仍在起约束作用而不是干扰。
2. 更可能的原因在融合结构本身：门控把持续锚点与气候态锚点的凸组合直接暴露给主损失，骨干在学习率降低后可以通过残差头记忆训练窗口的锚点偏差。验证这一点需要冻结门控或把锚点差距从残差头输入中移除，而不是继续调损失权重。
3. 在 BiST 骨干上追加同类小改动的边际价值已经很低。当前证据下 event 协议领先者仍是 STAEformer 版 NDR-Net，后续应回到该模型自身的输入通道与骨干条件化，或先在它身上复现并解释这种早期最佳后回升的形态，再决定下一步。
