## 证据与解释范围

全部七项完成 30 轮。三个 pooled 任务的最佳检查点均为第 30 轮，不能据此声称充分收敛。地区内 Graph H64、H240 在 Alameda 的最佳轮次分别为 9 和 11，在 ContraCosta 均为 1。该观察不改变原固定预算判读，也不证明所有后续配方都会失败。

两地区分别覆盖 6954 和 3472 条 validation 样本，累计有效点数分别为 35937114 和 17308933。比较核对相同 forecast origins、有效 targets、masks 和有效点分母。验证 MAE 按全部有效观测点累计，未用 affected 标签选择模型。协议为 protocol_v3_noleak_dedup，schema 3。

本轮为 seed 42 的开发比较。原 NDR 来源为 8260e6ca，Graph 和 SharedSTA 来源为 3b09dbf1，均为实际记录身份。NDR hidden16、microbatch8 与 Graph H64 或 H240、microbatch16 等差异须披露。pooled SharedSTA 使用 microbatch2，pooled Graph 使用 microbatch16，两者 effective batch 均为16。后续各种子必须保持各自原配方，不能称单因素或等算力比较。

源端七项及独立验证完成，148 个文件共 159443149 bytes 完整保全，复制前后清单和逐文件 SHA 一致。原 native、canonical adapter、Root 与独立 scorefree bridge 全部通过。原14 logical、15 physical、13次直接成功 wait 及两类不同未知退出 null 保持。冻结科学 consumer 实际返回 0，算术后重复新 schema 门禁及原八项完整闭合；原八项 No-Go 不变。没有在 Mac 重复 Torch 反序列化或 validation 推理。

## 后续决策

保留地区内 Graph 的负结果，停止其原配方确认。pooled H240 仅取得与 pooled SharedSTA 匹配的 seeds 1、2 确认资格，各种子仍须两地区严格改善。SharedSTA 因果历史归一化候选保持待执行，不能把本轮控制直接拼成它的新配对结果。

后继仍按已声明顺序推进：生产小图 CUDA 数值检查、DualCast 完整成本与成功或失败保全、STA 和 BiST 固定30轮强对照，再安排合格方向确认及归一化候选。Orange、最终 test 继续关闭，多种子、收敛与泛化结论尚待真实验证。
